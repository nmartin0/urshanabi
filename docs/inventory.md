# Asset inventory

Generated by `script/inventory` from the repository itself
(roadmap R-123). Do not edit: run the script. Reviewed on every
significant change, and at least every twelve months.

## Components

| Component | Language role | Holds | Speaks to |
|---|---|---|---|
| `conformance` | the agent and pipeline language for the behaviour properties; POSIX shell for the infrastructure checks and the drivers | nothing | each system under test, through its driver |
| `deploy` | declarative configuration | nothing; secrets are references (R-92) | the orchestration platform |
| `e2e` | to be decided | nothing | the whole system |
| `load` | to be decided | nothing | the whole system |
| `pipelines` | agent and pipeline language, and SQL | nothing beyond its workload identity | the orchestrator and the table format |
| `ui` | frontend language | nothing | the gateway only |
| `libs/ontology` | systems language | nothing | nothing on the network; it is a library |
| `services/agent` | agent and pipeline language | nothing | the query service, the model gateway and other agents |
| `services/audit` | services language | audit-log write access | audit events from every service |
| `services/control-plane` | services language | the signing keys | cells, through signed bundles |
| `services/gateway` | services language | sessions | browsers, API clients and external agents |
| `services/indexer` | systems language | index write access | the change log and the serving engine |
| `services/ingestion` | systems language | the source credentials, verified read-only | the source systems, and the raw layer |
| `services/model-gateway` | services language | short-lived model-provider credentials | model providers, and the agent |
| `services/query` | systems language | index and curated-layer read access | the gateway's and the agent's requests |
| `services/workflow-worker` | services language | nothing beyond its workload identity | the durable workflow engine and the write service |
| `services/write` | systems language | data-write and writeback credentials | the workflow worker's approved actions |

## Flows

What each component speaks to, from its own record.

- `services/agent` → the query service, the model gateway and other agents
- `services/audit` → audit events from every service
- `services/control-plane` → cells, through signed bundles
- `services/gateway` → browsers, API clients and external agents
- `services/indexer` → the change log and the serving engine
- `services/ingestion` → the source systems, and the raw layer
- `services/model-gateway` → model providers, and the agent
- `services/query` → the gateway's and the agent's requests
- `services/workflow-worker` → the durable workflow engine and the write service
- `services/write` → the workflow worker's approved actions
