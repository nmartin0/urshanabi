# Interface

Urshanabi's own design system and screens. It knows the backend only
through the client generated from `contracts/`, develops against a
mock generated from the same contracts, and can be built, tested and
deployed on its own.

- **Language role:** frontend language
- **Holds:** nothing
- **Speaks to:** the gateway only
- **Roadmap:** R-95, R-108, R-109

**Status:** planned; nothing is built yet. When work starts, this
project gains `script/bootstrap`, `script/test` and
`script/test-integration` (`RULES.md` E5).
